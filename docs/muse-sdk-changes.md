# Muse Gadget SDK 改动索引

按类别概括本项目相对上游 SDK 的适配。固定基线见 [来源清单](../upstream/sources.json)，新增能力见 [扩展功能索引](muse-sdk-extensions.md)。

- **2.16 实体键适配**：仅本板拆分扬声器、PWR 与 Talk，新增可取消的可靠 PMU 读清与硬件长按接入，限制休眠等待并调整顶部无框状态图标；保留其他板输入和旧 PMU 接口，安装检查兼容经核验的 Avatar/字体组合；组合固件刷机、启动及基础按键/图标人工核查已通过，长按时序与功耗待验收。见 [按键扩展](../bridge/extensions/waveshare-216-controls/README.md)。
- **Actell 接入**：将独立 Actell 组件接入官方命令注册、调用和会话生命周期，增加局域网连接设置页与 worker 启动接点，发现时区分网络位置和固定 TLS 身份以支持地址变化，保留默认关闭的开发 USB 配置入口；保留官方账户、配对和控制通道。配对页区分首次授权、确认与日常重连；移除手机选择列表，唯一窗口自动申请、多窗口停止并提示；显示批准、领取与最终确认阶段，默认名称为 Muse Gadget，旧待完成配对保留原名称。工具改为一级手机命令，截图一次返回 JPEG，捕获终态先释放运行再取缓存图；图片结果保留已校验的 JPEG 并流式编码发送，避免完整 base64 和大 JSON 副本，同次调用复用网络位置以减少重复发现，保留逐次 TLS 认证；输入不绑定截图，内部管理运行与原调用核对，错误退出及建运行回执丢失后核对并释放本次确认归属的运行，向外层错误保留远端原因与原操作编号，能力预检失败同样保留原始原因并明确未提交手机操作，并持久保存有限容量的调用身份；常规桥接配置启用截屏回传与手机读写头像动作，动画覆盖工具处理和取图过程，内部释放不清除动画且不因累计调用次数停更，模型图像可见性仍需实机验证。设置首页显示认证连接状态，支持位于配对操作下方、持久保存的自动重连开关；重连失败与取消保留配对，仅显式移除删除；认证请求须经本次启动的网络校时，发现后再取签名时间，避免 RTC 偏差导致拒绝；校时成功唤醒自动重连，不绕过用户关闭、取消或拒绝后的暂停。结果接收支持有界的大 JSON 并区分限额与网络故障，传输失败返回具体请求阶段和接收进度，串口阶段诊断覆盖 worker 与控制结果队列，不记录参数或身份；完成重复请求同步回应，工作槽回收与独立写请求去重保护并存。见 [Simple LAN 配对](slan-pairing.md)、[补丁说明](../bridge/patches/README.md) 与 [组件说明](../bridge/extensions/gadget-actell/README.md)。
- **无屏适配**：复用 Muse 文字会话，调整无屏构建与启动流程，增加文字事件观察和可选开发网页。见 [无屏控制台](headless-console.md)。
- **角色覆盖**：使用上游覆盖入口接入 v13，并通过薄改动分离原生网格与显示布局、增加编译回退和小头像重绘保护；保留现有构建机制及字体/TTS 接点，圆润着色版保留距离预筛与精确缓存、复用原安装入口，增加短锁保护的峰值/模式代次观察与独立嘴型通道，跨过短音频间隙并平滑闭口，保留仪表和眼睛的 UI 音量平滑，不改变刷新逻辑或新增完整帧缓冲。见 [角色说明](../bridge/extensions/avatar/README.md)。
- **字幕与共享资源适配**：通过可选薄补丁接入只读字体、真实行高和像素分页，恢复原版字号对应的三行回复、阅读区域与角色/音量条布局，保留顶部硬件适配，缺失或不兼容时回退原路径；资源布局保留既有数据与双 OTA，已完成首刷和启动核查，显示及回滚仍待验收。见 [字体集成](caption-font-integration.md)。
- **回复语音接点**：在会话的回复、播放及取消流程接入可选豆包 TTS，复用现有 PCM 输出和字幕；关闭扩展或扬声器时保留字幕节奏；长回复、打断与并行性能需单独验收。见 [TTS 说明](doubao-tts.md)。
- **配置适配**：提供桥接启停、无屏、板卡 USB 配置和中日韩字幕字体的配置组合，通过不回显值的工具导入及审计本机秘密配置，并根据豆包 API key 自动启停 TTS，通过构建参数显式选择双向（默认）或 HTTP 接口并核验宏，适配双向握手缓冲与内存分配，日志仅保留阶段及数值诊断。见 [组件配置](../bridge/extensions/gadget-actell/README.md#combining-existing-overlays) 与 [TTS 配置](doubao-tts.md)。

补丁应用与扩展暂存方式统一见 [补丁说明](../bridge/patches/README.md)。本项目只维护 Muse SDK 侧适配，Actell 应用在其独立工程维护。

- **已有账户配置保护**：避免仅为启动上报而刷新已有凭据；鉴权刷新或迁移被拒绝时保留配对与网络配置，显式重置仍由原入口处理。见[接入状态](actell-flat-tools-integration-status.md)。
