# 一级工具接入状态与平台缺口

## 源码接入

九工具已接到实际 `commands_v2` 注册和设备分发，旧 rpc/image/view 入口不再暴露。共享 [FLAT-TOOLS-1](protocol/FLAT-TOOLS-1.md) 与 Actell 仓库原文逐字一致；SLAN 配对契约未改。

- `actell_flat.c`：工具元数据、直接参数校验、固定契约门控和无 observation 调用参数构造；输入使用 0～1000 归一化坐标，不要求截图；首版省略未经平台验证的启动参数数组。
- `actell_flat_execute.c`：能力协商、逐 invoke 独立 run、单次提交、原调用轮询、终态释放、截图与取图合并、历史状态查询。本地 wait 不创建手机 run。
- `actell_flat_store.c`：通过真实 ESP-IDF NVS API 先持久化调用身份、规范参数、配对所有权摘要及固定期限，再允许手机 I/O；重复只核对原调用，异参数或异配对所有权拒绝。
- `actell_bridge.c` / SDK hook：接入真实 worker 和公开入口；SDK 原 JSON 入口拒绝无效 UTF-8、嵌入 NUL 或过大消息；结果继续沿官方 camera 图片位置返回，SDK 对 Actell 整体结果实施独立限额。

没有固定 60 秒 run 或 5 秒空闲释放。每次调用使用平台超时预算内的明确截止时间，正常思考期间没有共享 run 被空闲定时器打断。

## 持久化容量与故障边界

公开目标分区定义 NVS 总量为 48 KiB，其他配置也使用该分区。本次没有读取实机 NVS 内容或秘密配置，因此实际空闲页数及最终可用调用容量尚未测量。

每条 v1 记录 56 字节：invoke、规范参数、配对所有权各 16 字节 SHA-256 指纹，以及 8 字节固定期限。原 run/call/operation ID 均由完整 invoke SHA-256 稳定派生。指纹碰撞只能拒绝或进入原记录核对，不允许作为新动作提交。记录不含原始用户文本、图像或秘密。

每块 8 条记录，块大小 456 字节；72 字节预留 header 原子保存待插入的完整记录。header 先提交，再插入块、完成 header；重启修复同一预留，不重新执行动作。独立初始化 sentinel 可发现 ledger 丢失。缺少已分配块、记录损坏、写入失败或容量不足均拒绝新动作。

初始化通过 `nvs_get_stats` 按空闲 entry 计算容量，预留 128 entries 给其他配置/GC，并预留两个块及 header 写入空间，上限 512 条。NVS blob 的索引、分页和碎片仍可能使后续写入提前失败，届时拒绝手机 I/O；不能把理论 entry 数当作实机可用容量保证。合成 free_entries=1000 时容量为 384 条，这只是计算夹具，不是设备测量。

所有已登记身份永久保留，不按 TTL、终态、重连或重新配对自动删除。满容量后原记录查询仍可用；新动作返回 storage_full。失败前置检查也可能消耗一个安全预留身份。这个累计有限容量是首版重要限制，长期归档尚未实现。

同一连接近期重复请求还由 RAM guard 校验参数摘要；重启/连接代次更换后由永久记录阻止重放。未发送入队失败不会写 NVS。记录清空或全部存储连同 sentinel 被人为删除后，再恢复旧秘密的情形不在本次更新保证内；不自动擦除、修复或重建已丢失的非空历史。

## 图片与注册预算

| 通道 | 限额或实际测算 |
|---|---|
| HTTP 普通 RPC JSON 响应 | 256 KiB |
| HTTP JPEG 二进制响应 | 256 KiB；保留哈希、身份、格式和尺寸校验 |
| 最大 JPEG 的 base64 | 349528 字节 |
| Actell 完整 SDK link.result | 360 KiB，含图片与元数据；超过时返回保留 operation ID 的小错误 |
| HTTP 请求 / 原 JSON 入口 | 64 KiB，覆盖文本转义开销；不是注册缓冲区扩容 |
| 九工具及合成全功能 SDK 注册消息 | 6954 字节，距 8192 上限 1238 字节 |

注册使用固定 SDK 的实际序列化器、较长合成身份和可选设备功能组合；不是当前板卡实际清单。参数大小仍受平台实际传输能力约束，不能把 JSON schema 当成平台透传验收。

截图 payload 在原 `format/data_base64` 同层附 operation_id、state、effect、image_status、坐标约定及捕获/到期时间。capture 成功但 fetch/交付失败时，外层 ok=false，保留成功捕获状态和可用元数据，不再次截图。状态查询可取原历史图；可下载不表示它是当前画面。

## 截图回传优化

正常截图和历史图片结果保留一份通过完整身份、哈希及尺寸校验的 JPEG，元数据先序列化为小 JSON，base64 在现有控制通道分块发送时生成。图片不再产生完整 base64 临时串、JSON 字符串副本及大 JSON 序列化缓冲；完整 JPEG 仍驻留内存。线上格式、图片及结果上限不变，上传块仍沿用 SDK 的板卡适配值。队列丢弃、会话切换、发送失败和断开均释放图片所有权。

每次外层工具调用独立保存临时网络位置，成功 HTTP 交换后供其后续 RPC 复用，结束即丢弃；身份或子网不符、任一交换失败时失效。没有跨调用持久缓存，不跳过 TLS/HMAC，不重放失败动作。增加发现、TLS、读取与总耗时，以及图片上传耗时和块数统计，尚需真机区分实际瓶颈；不能将内存优化等同于已测得延迟改善。

## 验证与部署边界

主机回归覆盖真实注册、真实 SDK 结果序列化、真实适配器和真实 NVS 存储算法。网络、调度、NVS 和部分 hash/编码依赖使用明确的合成夹具；ASan/UBSan 检查参数边界、提交顺序、重启、写入前后故障、容量满、丢 ledger、异参冲突、历史图读取以及最大结果边界。不是实机掉电、Flash 寿命或 JPEG 解码验收。

完整目标构建复用现有配置，检查头像、字体、TTS、SLAN、图片回传和手机活动动画功能；构建输出和凭据检查均留在私密 local 内，仅输出状态。构建证据在 local/validation/flat-tools 与 local/logs/flat-tools；刷写、原始配置恢复和启动证据在 local/validation/flat-tools-preserved 与 local/logs/flat-tools-preserved。

平台缺口：固定 SDK 没有任务 ID、任务结束和取消通知；逐 invoke run 是回退，不宣称任务级取消。首次回执完全丢失时，平台能否交付原 invoke ID/自动发起原调用查询仍未证实；不得猜 ID 或创建替代动作。

Actell 远程入口不增加前台、前台历史、同客户端续接或 source receipt 准入门槛；后台任务由公共生命周期保护、实际连接与超时处理，锁屏、权限、并发和禁止重放仍保留。Gadget 不共享跨任务 run。跨 App 连续控制仍需真机验收，不能仅凭两端编译与合成测试宣布可用。

已按用户授权刷入当前分支修正版并恢复刷写前的原始 NVS，应用、NVS、资源及启动槽均经核对；保留原字体资源和另一槽回退固件，未改分区。首次启动曾因 SDK 认证失败逻辑自动清除配置，现已修复并从原始备份恢复。后续已按授权刷入包含错误退出运行释放修复的固件，保留当时现有 NVS、网络及资源；启动检查无崩溃或看门狗超时，设备只读状态报告 Wi-Fi 已连接、Muse 已配对、控制在线且聊天已连接。此状态不代表手机工具端到端验收。未执行手机截图或输入验收，未直接读取秘密配置，未自动提交 Git。

正常终态关闭 run 后，仅以原 runs.get 的 execution_released=true 确认执行权已释放；在剩余预算内只读轮询，缺字段、超时或失败则返回 run_released=false，不抹去已确认动作结果，也不重新提交动作。跨 App 后台执行交给 Actell 既有公共保护与实际连接结果，Gadget 不跨任务共享 run 或虚构任务身份。

最终本侧验证：102 项主机回归、22 项字体回归、9 项按键回归，以及 Node/observer 检查通过；固定 SDK 的完整目标固件构建通过，ELF 确认一级工具、持久化和结果限额实现已链接，旧 view 编排已移除。权威组件与构建暂存逐字一致。分享检查 242 个 Git 可见文件、零发现，差异格式检查通过；已部署并确认字体加载、无启动崩溃或看门狗超时，未提交。部署不代表新工具已通过 Muse 与手机端到端验收。

启动鉴权保护：SDK token 上报不再单独触发已有凭据刷新；刷新或 mint 被拒绝时保留已有配对和 Wi-Fi，不触发自动设置删除。显式用户重置与外部解除配对语义不变；对应真实 SDK 函数以合成凭据验证。

运行释放覆盖本次已确认创建的运行在提交错误、轮询错误、无效或未知回执、未完成返回和终态的所有退出；丢失 open 回执时仅查询确定的原 run ID 建立归属后收尾。被拒绝的 open、异 run ID、重复 invoke 核对及 call_status 不取得或释放执行权。取消只发送一次，之后每 100 ms 只读确认释放，最多 20 次，不把取消确认当成释放完成；剩余预算不足或连接代次失效则如实返回 run_released=false。工具状态每 500 ms 查询，设备工作预算为入队起 40 秒，手机截止时间使用剩余预算减 5 秒，平台注册超时为 60 秒。网络请求也占预算，因此轮询次数上限不是整个释放 HTTP 阶段的硬性 2 秒超时。该修复已随当前分支固件部署并完成启动与 Muse 在线检查，Actell App 更新及手机工具端到端验收另行确认。

错误展示保留远端工具终态及取图失败的公开原因，同时在顶层 message 附原操作编号，避免平台只显示 message 时丢失核对入口。截图分别报告元数据无效、预算已尽、图片响应不匹配和取图失败，不改变已确认的原 state/effect。此错误可见性修复已随当前固件部署，手机工具验收另行确认。

建运行回复丢失的核对同时覆盖空返回和实际传输层包装的 unknown/transport_error/protocol_error/response_too_large 对象；只读查询原 run ID 证实归属后释放，不重发建运行或工具动作。明确 busy 拒绝不取消他人的运行。该遗漏修复已随当前固件部署。

截图收到成功终态后先释放本次运行，再按原身份下载保留图；取图不重拍。释放确认结果独立附在图片成功或失败结果上，取图耗尽预算不再阻止此前的释放尝试；历史查询仍不释放 owner。该调整未新增固定等待或准入拦截，已随当前固件部署，启动和 Muse 在线检查通过；截图后连续输入的真机验收另行确认。

最新部署记录位于 local/validation/release-before-image-flash：应用回读及保护区域校验通过，字体加载成功，无启动崩溃或看门狗超时；设备状态显示 Wi-Fi 连接、Muse 配对、控制在线及聊天连接。没有触发手机截图或输入，不将在线检查写成手机工具端到端验收。

手机读写动画绑定单个 worker 的外层任务生命周期，从开始处理有效请求到结果完成，覆盖发现、连接、排队、轮询、释放及取图，不以动画宣称手机实际执行成功。内部运行释放不能清除外层动画；历史记录复用与取消记录轮转避免累计停更。动画租期沿用工具剩余预算，不增加调用、等待或截止时间；语音等原有优先级保留。该显示修复已刷入，应用及保护区域校验、字体加载和启动检查通过，Muse 控制与聊天在线；本轮未触发手机操作，实物动画可见性仍待验收。

HTTP 失败返回原 RPC 步骤、传输阶段、ESP 错误名、状态码、期望与已接收字节及原始 read 返回值；内存不足与连接错误分开报告。诊断不包含地址、请求内容、图片、凭据，不增加网络调用或等待。该诊断细分尚未部署；不能用它倒推出旧失败未记录的错误。
