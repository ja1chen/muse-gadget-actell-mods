# 一级工具接入状态与平台缺口

## 源码接入

九工具已接到实际 `commands_v2` 注册和设备分发，旧 rpc/image/view 入口不再暴露。[FLAT-TOOLS-1](protocol/FLAT-TOOLS-1.md) 的线上调用格式与 Actell 兼容；设备端记录保留方式已改为内存，SLAN 配对契约未改。

- `actell_flat.c`：工具元数据、直接参数校验、固定契约门控和无 observation 调用参数构造；输入使用 0～1000 归一化坐标，不要求截图；首版省略未经平台验证的启动参数数组。
- `actell_flat_execute.c`：能力协商、逐 invoke 独立 run、单次提交、原调用轮询、终态释放、截图与取图合并、历史状态查询。本地 wait 不创建手机 run。
- `actell_flat_store.c`：在单 worker 的内存缓存中记录调用身份、规范参数、配对所有权摘要及固定期限，再允许手机 I/O；重复只核对原调用，异参数或异配对所有权拒绝。
- `actell_bridge.c` / SDK hook：接入真实 worker 和公开入口；SDK 原 JSON 入口拒绝无效 UTF-8、嵌入 NUL 或过大消息；结果继续沿官方 camera 图片位置返回，SDK 对 Actell 整体结果实施独立限额。

没有固定 60 秒 run 或 5 秒空闲释放。每次调用使用平台超时预算内的明确截止时间，正常思考期间没有共享 run 被空闲定时器打断。

## 内存容量与回收边界

设备不再持久化手机操作历史。`actell_flat_store.c` 仅保留最近 64 条记录，每条 56 字节，总记录区 3.5 KiB，启用外部 BSS 的目标固件将其静态放入 PSRAM；新操作复用最旧槽位，单 worker 保证上一次执行已经结束。查询不分配记录；淘汰后或重启后的旧操作查询返回 unavailable，不据此重新执行。

手机活动跟踪表另有约 5.2 KiB，同样在启用外部 BSS 时放入 PSRAM。两者都是单 worker 使用的普通数据，不参与中断或 DMA；静态迁移只改变链接位置，不增加分配失败路径。

连接缓存同样受内部内存预算约束：仅在请求已完整结束、连接交回 worker 时，检查可用 DMA 总量和最大连续块。总量低于 24 KiB 或连续块低于 2 KiB 时关闭可选的空闲连接；空闲维护也检查该条件。保留三十秒地址缓存，不发送额外 RPC、不取消运行、不重放动作，下一次请求重新进行 TLS/HMAC 认证。正在使用或读取响应的连接不会被此回收路径关闭。SDK 原有的结果准备及逐块发送门槛保持不变；24 KiB 是空闲连接保留门槛，为 16 KiB 发送门槛留出 8 KiB 余量。

独立的 admission guard 在当前控制代次保留写请求摘要，缓存淘汰不会使同一代次的旧操作再次提交。原有代次写请求上限继续生效。重启会清空全部内存历史；跨代次且缓存已淘汰的请求也不提供永久去重保证，调用方不得重发结果不确定的操作。

固件不再包含旧操作账本的读写、恢复或启动清理逻辑。已有设备的旧账本已经通过一次性维护清理，证据仅保留在本机验证目录。配对身份独立存储为精简 `peer_v3`，仅保存字段实际长度，固定头部、secret 和二进制指纹合计 78 字节；旧格式不读取、不迁移、不回退，需要重新批准配对。自动连接、官方账户和 Wi-Fi 配置仍保留。NVS 仍为原 48 KiB 分区，操作缓存不再占用它。

## 图片与注册预算

| 通道 | 限额或实际测算 |
|---|---|
| HTTP 普通 RPC JSON 响应 | 256 KiB |
| HTTP JPEG 二进制响应 | 256 KiB；保留哈希、身份、格式和尺寸校验 |
| 最大 JPEG 的 base64 | 349528 字节 |
| Actell 完整 SDK link.result | 360 KiB，含图片与元数据；超过时返回保留 operation ID 的小错误 |
| HTTP 请求 / 原 JSON 入口 | 64 KiB，覆盖文本转义开销；不是注册缓冲区扩容 |
| 九工具及合成全功能 SDK 注册消息 | 6954 字节，距 8192 上限 1238 字节 |

注册使用固定 SDK 的实际序列化器、较长合成身份和可选设备功能组合；不是当前板卡实际清单。参数大小仍受平台实际传输能力约束，不能把 JSON schema 当成平台透传验收。

截图 payload 在原 `format/data_base64` 同层附 operation_id、state、effect、image_status、坐标约定及捕获/到期时间。capture 成功但 fetch/交付失败时，外层 ok=false，保留成功捕获状态和可用元数据，不再次截图。状态查询可取原历史图；可下载不表示它是当前画面。

## 截图回传优化

正常截图和历史图片结果保留一份通过完整身份、哈希及尺寸校验的 JPEG，元数据先序列化为小 JSON，base64 在现有控制通道分块发送时生成。图片不再产生完整 base64 临时串、JSON 字符串副本及大 JSON 序列化缓冲；完整 JPEG 仍驻留内存。线上格式、图片及结果上限不变，上传块仍沿用 SDK 的板卡适配值。队列丢弃、会话切换、发送失败和断开均释放图片所有权。

外层工具调用之间可以有界复用 HTTP/TLS 连接，身份、网络或控制代次变化以及传输失败会使其失效；业务空闲上限为十分钟，短期网络地址缓存独立保留三十秒。复用仍然逐请求进行 HMAC 鉴权，不重放失败动作。增加发现、TLS、读取与总耗时，以及图片上传耗时和块数统计，尚需真机区分实际瓶颈；不能将内存优化等同于已测得延迟改善。

## 验证与部署边界

主机回归覆盖真实注册、真实 SDK 结果序列化、真实适配器和内存缓存。网络、调度、NVS 和部分 hash/编码依赖使用明确的合成夹具；ASan/UBSan 检查参数边界、单次提交、缓存循环回收、重启清空、异参冲突、历史图读取以及最大结果边界。HTTP 生命周期回归覆盖内存不足时拒绝保留空闲连接、精确阈值、空闲期间回收、连续块不足、活跃借用连接保护、恢复后的新认证及地址缓存保留；不增加请求或重放。上游传输回归保留原有 DMA 门槛、暂停恢复、单条所有权、心跳及失败清理检查。不是实机掉电、Flash 寿命或 JPEG 解码验收。

完整目标构建复用现有配置，检查头像、字体、TTS、SLAN、图片回传和手机活动动画功能；构建输出和凭据检查均留在私密 local 内，仅输出状态。精简配对格式的构建与刷写证据分别保留在 local/validation/compact-pair 和 local/validation/compact-pair-flash，对应原始日志在 local/logs 下。此前一次性旧账本清理证据在 local/validation/ram-operation-cache-flash。

平台缺口：固定 SDK 没有任务 ID、任务结束和取消通知；逐 invoke run 是回退，不宣称任务级取消。首次回执完全丢失时，平台能否交付原 invoke ID/自动发起原调用查询仍未证实；不得猜 ID 或创建替代动作。

Actell 远程入口不增加前台、前台历史、同客户端续接或 source receipt 准入门槛；后台任务由公共生命周期保护、实际连接与超时处理，锁屏、权限、并发和禁止重放仍保留。Gadget 不共享跨任务 run。跨 App 连续控制仍需真机验收，不能仅凭两端编译与合成测试宣布可用。

已按用户授权刷入当前分支修正版并恢复刷写前的原始 NVS，应用、NVS、资源及启动槽均经核对；保留原字体资源和另一槽回退固件，未改分区。首次启动曾因 SDK 认证失败逻辑自动清除配置，现已修复并从原始备份恢复。后续已按授权刷入包含错误退出运行释放修复的固件，保留当时现有 NVS、网络及资源；启动检查无崩溃或看门狗超时，设备只读状态报告 Wi-Fi 已连接、Muse 已配对、控制在线且聊天已连接。此状态不代表手机工具端到端验收。未执行手机截图或输入验收，未直接读取秘密配置，未自动提交 Git。

正常终态关闭 run 后，仅以原 runs.get 的 execution_released=true 确认执行权已释放；在剩余预算内只读轮询，缺字段、超时或失败则返回 run_released=false，不抹去已确认动作结果，也不重新提交动作。跨 App 后台执行交给 Actell 既有公共保护与实际连接结果，Gadget 不跨任务共享 run 或虚构任务身份。

当前本侧验证：112 项主机回归、23 项字体回归、9 项按键回归，以及 Node/observer 检查通过；固定 SDK 的完整目标固件构建通过，RAM 缓存对象没有 NVS 引用，正式固件没有旧格式兼容或启动清理逻辑。权威组件与构建暂存逐字一致。旧操作条目、标记和旧配对已按授权一次性清除；新配对回读为 803 字节的 active 记录，完整性与证书指纹校验通过，重启后自动连接已由用户确认。官方账户、Wi-Fi、自动连接偏好和资源保持不变，正式固件启动时 RAW-AA、字体及 Muse 在线，无回退、崩溃或看门狗超时。详细证据保留在本机验证目录。验证脚本仅发送设备状态查询，但重启期间另有上层下发的 launch_app 请求，随后手机回执确认新编号的 launch_app 执行成功；不能把脚本未发送控制指令等同于设备没有收到操作。用户已确认这些请求来自服务端 LLM 在收到超时错误后的重试；不同调用编号不属于设备本地重放，不将此意外调用写成完整手机工具验收。未执行截图、输入或语音验收，未提交 Git。

启动鉴权保护：SDK token 上报不再单独触发已有凭据刷新；刷新或 mint 被拒绝时保留已有配对和 Wi-Fi，不触发自动设置删除。显式用户重置与外部解除配对语义不变；对应真实 SDK 函数以合成凭据验证。

运行释放覆盖本次已确认创建的运行在提交错误、轮询错误、无效或未知回执、未完成返回和终态的所有退出；丢失 open 回执时仅查询确定的原 run ID 建立归属后收尾。被拒绝的 open、异 run ID、重复 invoke 核对及 call_status 不取得或释放执行权。取消只发送一次，之后每 100 ms 只读确认释放，最多 20 次，不把取消确认当成释放完成；剩余预算不足或连接代次失效则如实返回 run_released=false。工具状态每 500 ms 查询，设备工作预算为入队起 40 秒，手机截止时间使用剩余预算减 5 秒，平台注册超时为 60 秒。网络请求也占预算，因此轮询次数上限不是整个释放 HTTP 阶段的硬性 2 秒超时。该修复已随当前分支固件部署并完成启动与 Muse 在线检查，Actell App 更新及手机工具端到端验收另行确认。

错误展示保留远端工具终态及取图失败的公开原因，同时在顶层 message 附原操作编号，避免平台只显示 message 时丢失核对入口。截图分别报告元数据无效、预算已尽、图片响应不匹配和取图失败，不改变已确认的原 state/effect。此错误可见性修复已随当前固件部署，手机工具验收另行确认。

建运行回复丢失的核对同时覆盖空返回和实际传输层包装的 unknown/transport_error/protocol_error/response_too_large 对象；只读查询原 run ID 证实归属后释放，不重发建运行或工具动作。明确 busy 拒绝不取消他人的运行。该遗漏修复已随当前固件部署。

截图收到成功终态后先释放本次运行，再按原身份下载保留图；取图不重拍。释放确认结果独立附在图片成功或失败结果上，取图耗尽预算不再阻止此前的释放尝试；历史查询仍不释放 owner。该调整未新增固定等待或准入拦截，已随当前固件部署，启动和 Muse 在线检查通过；截图后连续输入的真机验收另行确认。

运行释放调整时的部署记录位于 local/validation/release-before-image-flash：应用回读及保护区域校验通过，字体加载成功，无启动崩溃或看门狗超时；当时设备状态显示 Wi-Fi 连接、Muse 配对、控制在线及聊天连接。没有触发手机截图或输入，不将在线检查写成手机工具端到端验收。

手机读写动画绑定单个 worker 的外层任务生命周期，从开始处理有效请求到结果完成，覆盖发现、连接、排队、轮询、释放及取图，不以动画宣称手机实际执行成功。内部运行释放不能清除外层动画；历史记录复用与取消记录轮转避免累计停更。动画租期沿用工具剩余预算，不增加调用、等待或截止时间；语音等原有优先级保留。该显示修复已刷入，应用及保护区域校验、字体加载和启动检查通过，Muse 控制与聊天在线；本轮未触发手机操作，实物动画可见性仍待验收。

HTTP 失败返回原 RPC 步骤、传输阶段、ESP 错误名、状态码、期望与已接收字节及原始 read 返回值；内存不足与连接错误分开报告。诊断不包含地址、请求内容、图片、凭据，不增加网络调用或等待。该诊断已随内存优化固件部署；不能用它倒推出旧失败未记录的错误。

本轮内存优化将三组静态记录迁入 PSRAM，链接结果确认内部静态占用减少 8,896 字节，并加入内存压力下的空闲 TLS 回收。完整目标构建、主机回归和固定 SDK 的 9 项传输回归通过；应用回读、原 NVS、资源及回退槽保护校验通过，启动和 Muse 在线检查正常。当前固件的四次只读 list_apps 均执行成功并由平台收到成功结果，包含连续两次调用和重启后调用；结果入队至发送分别为 125、942、114、134 ms，无平台超时。空闲连接回收样本释放 6,140～6,148 字节 DMA 内存，其中三次由 15,775 升至 21,915 字节，越过原有 16 KiB 发送门槛。内存紧张时下一次请求需要重新建立 TLS，不将这些样本当作所有负载的延迟保证。此前无法发现 iPhone 的错误回执入队至发送耗时 42 ms，平台收到明确错误而非超时。长任务、截图与手机写操作未在本轮验收；不把此前候选固件的成功样本计入本轮。详细数值与原始日志仅保留在 local/validation/psram-memory/delivery.json、local/validation/psram-idle-pressure 及相关本机目录。
