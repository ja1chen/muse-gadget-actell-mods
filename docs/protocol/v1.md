# Muse → Actell remote tools v1 (frozen wire contract)

Only POST /v1/rpc. UTF-8 JSON body:
`{"v":1,"client_id":"configured-client","request_id":"UUID","op":"capabilities","params":{}}`.
Identifiers are opaque 1–128 character ASCII `[A-Za-z0-9_-]` (UUID hyphens allowed). Deadline/timestamps are integer Unix milliseconds, except auth header seconds. Maximum request body 1 MiB.

Headers `Content-Type: application/json`, `X-Actell-Time` (canonical decimal Unix seconds, no leading zeros), `X-Actell-Nonce` (UUID), `X-Actell-Signature` (lowercase hex).
Signature = HMAC-SHA256(key, UTF8(`ACTELL1\n{client_id}\n{request_id}\n{time}\n{nonce}\n`) || **exact body bytes**). Decode JSON only to obtain identity and envelope; never reserialize before verifying. Reject duplicate JSON keys. Client secret configured by user, never shipped or automatically provisioned. Authenticate every operation including reads. ±60 seconds clock skew; reject reused `(client_id, lowercase(nonce))` for 120 seconds; signature still uses the exact nonce header bytes. TLS with system trust/custom CA mandatory outside explicit loopback mock. No redirects. TLS termination must pass bytes unchanged over a private authenticated path. L3 Muse Noise/NAPT tunnel remains unchanged; HTTPS is application endpoint transport, no additional board-side encryption/tunnel layer.

Responses: `{"v":1,"request_id":"...","ok":true,"result":{...}}` or `{"v":1,"request_id":"...","ok":false,"error":{"code":"...","message":"...","retryable":false}}`. HTTP 200 for authenticated RPC success/error, HTTP 400 malformed envelope, 401 auth/replay failure, 413 oversized body. Do not infer nonexecution from HTTP/network failure.

## Operations
- `capabilities {}` → `{tools:[{name,description,parameters}],transport:"https",approval:"existing-app-policy",image_encoding:"binary"}`. Tool JSON-schema parameters describe the exact allowed Actell tool names. Remote clients cannot change approval policy or register tools.
- `runs.open {run_id,deadline_ms}` → `{run_id,state:"open",deadline_ms}`. Bind run permanently to authenticated client. Same run/deadline is idempotent; different deadline conflicts. Future deadline required, max 1 hour.
- `runs.get {run_id}` → run record, state `open|cancelled|expired`.
- `runs.cancel {run_id}` → run record. Stops new calls, requests cancellation of queued/running calls; cannot promise rollback or cancellation of an already-dispatched tool. Already-running uncertain results remain `unknown` unless confirmed.
- `tools.call {run_id,call_id,deadline_ms,tool,arguments,observation?}` → call record. `observation:{image_id,generation}` required for coordinate actions (tap/swipe/drag etc.) and validated at actual dispatch against current screenshot generation. Bind call_id to client/run, exact semantic payload (including deadline, tool, args, observation). Same payload returns same record and NEVER reexecutes; changed payload → `idempotency_conflict`. Deadline must be future and <= run deadline. Queue behind existing app approval/execution path; Muse is the only planner.
- `calls.get {run_id,call_id}` → call record `{run_id,call_id,state,result?,error?}`. States `pending_approval|queued|running|succeeded|failed|cancelled|expired|unknown`. Terminal unknown means outcome cannot be established; do NOT repeat the action under a new ID. Poll/reconcile only. Client never automatically retries tools.call after transport failures; it may query calls.get. `not_found` after a timeout is not proof that an earlier call cannot still arrive.
- `images.get {run_id,image_id,generation}` → HTTP 200 raw PNG/JPEG bytes with Content-Type image/png or image/jpeg, Content-Length and headers `X-Actell-Image-Id`, `X-Actell-Generation`, `X-Actell-Width`, `X-Actell-Height`, `X-Actell-SHA256`, `X-Actell-Request-Id`. Error responses remain JSON. Max image 8 MiB. Screenshot result contains `{image_id,generation,width,height}`. Images are bound to owning client/run, temporary in-memory storage only on Actell; fetch explicitly. Generation increments on each captured screenshot and dispatched screen mutation. Old coordinates are rejected as `stale_observation`; image fetch can return retained older snapshots. No board image storage. A downloaded image file does not prove Muse's model has visual input; model image injection is a host-specific integration step.

Suggested error codes: `bad_request`, `unauthorized`, `replay`, `not_found`, `forbidden`, `idempotency_conflict`, `deadline_exceeded`, `run_closed`, `stale_observation`, `tool_not_allowed`, `approval_required`, `internal_error`.

## Durability and privacy
The production adapter must persist accepted call IDs/semantic payloads and outcomes, or refuse all writes after restart until explicitly reconciled. Never erase accepted IDs while retries could occur. The reference mock is intentionally process-local; restarting it loses all state and is not a production guarantee. Production TLS listener is disabled by default; no public endpoint is activated. User must explicitly configure identities, secrets, trusted network/TLS, approvals, and on-device activation. BLE is a future byte-transport extension only, NOT implemented.
